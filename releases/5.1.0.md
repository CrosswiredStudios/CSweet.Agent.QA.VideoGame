# 5.1.0

QA can test its actual static web build in reusable isolated compute with Playwright and Chromium. The `test_web_build` tool pins the authorized source identity, commit, immutable build archive and requested viewports. Browser failures cannot produce a passing QA report. Screenshots, traces and their digest-checked archive are retained in the source-bound QA journal.

Build transfer, browser execution and evidence transfer checkpoint exact compute requests before submission. Lost responses reuse the same operation and key. QA yields `awaiting-compute` and resumes through platform completion wakes with bounded recovery, rather than occupying an agent while polling.

Requires the matching platform and a newly prepared `browser-testing-v1` compute image. Review the requested `compute.provision.v1`, `compute.read.v1` and `compute.execute.v1` grants through Installed Agents. Static build assets must be self-contained; backend-dependent applications, real-device compatibility, gameplay and performance remain separate checks. This package does not install a browser in the QA agent VM.
