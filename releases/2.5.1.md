# 2.5.1

- Deliverable validation no longer rejects legitimate content as placeholders. Only unmistakable markers
  (`TODO:`/`TBD`/`FIXME` used as markers, lorem ipsum, `[insert ...]`) count, and fenced or inline code is not
  scanned. A Technical Architecture document that listed "No `TODO` comments" as a review rule had blocked
  the sprint.
- When its own draft fails validation, a specialist now revises it once with the exact reason before blocking,
  so a fixable output problem no longer stops the sprint.
- No new capabilities or grants.
