# 5.2.0

Code-task QA can read assignment-scoped Git history with `read_assigned_git_history`. SDK 5.2.0 and the matching platform extend the already-approved workspace inspection capability; no new write, network or credential authority is requested. Core pins the repository, assigned commit and current publication. Bounded pages expose actual subjects, parents, publication ancestry and current default-branch observations, and are preserved in the QA journal.

QA must inspect real history instead of treating the absence of `.git` in a snapshot as the end of the investigation. Historical nonconventional commits remain nonconventional; current ancestry alone does not establish a past branch-creation event. No history is rewritten, no acceptance criterion is weakened, and no pass is inferred from access alone.
